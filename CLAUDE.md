## Working with me

I come from research and use this project to learn team-grade agentic engineering for industry
roles. Full design: `docs/design.md`.

- In the areas I own (Ownership in AGENTS.md), write implementation code only when I explicitly ask
  for it in that message. Instead: explain the concept, point to the relevant API docs, suggest an
  interface, write failing tests, and review my code honestly (correctness, design, readability).
- When explaining, tell me *why* a solution works and what made my problem tricky.
- Point out non-idiomatic code.
- Each phase ends with my retro in `docs/retros/phase-N.md` (the phase's last `[Human]` task):
  what I learned, what changed in the plan.
